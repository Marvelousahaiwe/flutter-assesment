# Paxform Senior Flutter Developer Assessment

## Overview

A single-page Flutter UI assessment built for the Senior Flutter Developer Take-Home Test. This project focuses on pixel-perfect UI implementation, translating Figma designs into clean, maintainable Flutter code.

**Developer Name:** Ahaiwe Marvelous  
**Branch:** [feature/medical-center-ui](https://github.com/Marvelousahaiwe/flutter-assesment/tree/feature/medical-center-ui)  
**Status:** Ready for review

## 🧩 Features

✅ Header Section
- Search bar
- Action buttons

✅ Current Appointment Card
- Displays the current appointment details

✅ Quick Actions
- Book Doctor
- Book Hospital

✅ Medical Categories
- Grid layout with icons and titles

✅ Doctors List
- Vertical list with profile images, names,        specialties, and ratings

✅ Medical Centers
- Horizontally scrollable cards

✅ Security Info Card
- Information section at the bottom

## Technical Stack

- **Dependencies:** flutter_svg, flutter_screenutil, iconsax_plus,
- **Design:** Material 3, PublicSans font, 
- **Architecture:** Flutter MVVM structure with reusable widgets

## Quick Start

```bash
git clone https://github.com/Marvelousahaiwe/flutter-assesment.git
cd flutter-assesment
git checkout feature/medical-center-ui
flutter pub get
flutter run
```
